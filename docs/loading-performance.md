# 加载性能优化

日期：2026-10-21。保持原生多页面、原图、正文、署名、模型精度与原有转场时长。

## 首次加载

- 总览使用 128px WebP 星图/目录预览与选中天体的 512px 预览；原 PNG 保留。
- 九个档案的模型依赖放在 inert template，由 `shared/model-loader.js` 在模型区域可见且页面处于前台时加载。阅读界面先初始化。脚本并行预加载、按依赖顺序执行；每次脚本加载设 30 秒超时，失败显示既有图文回退，九个模型入口均阻止失败后的迟到初始化。
- 火星巡视器三图使用 lazy，打开面板、选车、深链接后正常加载。在线模型和地图复用同一 JPG，TextureLoader 使用与 HTML 图片一致的同源请求模式；file:// 使用保留的内嵌贴图。避免为 HTML 本地图片强制 crossorigin，保证离线查看。
- 火星系统全景只加载卫星边界参数；近看火卫一/二时才加载对应原始几何和贴图，加载完成不覆盖用户的后续选择，失败后不重建场景。
- 木星在线按观察目标读取原 JPG；初始只准备木星，单颗卫星近景只加载该卫星，系统全景加载其余天体。请求去重，加载中失效后由公共纹理生命周期丢弃迟到结果。file:// 仍使用完整内嵌数据。
- 44 张正文影像提供 480px 和至多 960px 的等比 WebP（quality 84、alphaQuality 100、禁止放大），通过 srcset/sizes 选取。lazy 图片的 sizes 使用 auto 读取实际展示宽度，同时保留旧浏览器尺寸回退；宽卡片不会被统一当成小卡片。img.src、data-image-full、弹窗和来源资料仍指向原图。新增或更换原图时同步更新 assets/previews 中的相应预览；不要把小预览用于模型贴图、地图或放大窗口。自动尺寸依据 [HTML 标准](https://html.spec.whatwg.org/dev/images.html)。

## 跨页与复访

`shared/vendor/` 统一八份相同 Three.js 和七份相同 OrbitControls 的当前引用；原路径保留兼容旧页面。火星定制库和金星 controls 不合并。

构建在输出内生成 `shared/cache/<sha256 前 12 位>/<原路径>`，哈希依据最终输出字节。CSS URL 根据新位置重写，保证 HTTP 与 file:// 都可用。HTML 保留其他查询参数与 URL 片段，继续携带同一内容版本参数。旧源路径仍可访问；源码不会被构建改写。

`_headers` 只将内容地址目录设为一年 immutable；HTML、各页原 JS/CSS 及 shared 原文件分别重新校验，规则不与内容地址目录重叠。规则数低于 Cloudflare Pages 的 100 条上限。[平台文档](https://developers.cloudflare.com/pages/configuration/headers/)。线上是否生效取决于 Pages 发布 dist 与外部缓存规则，Git 推送不能证明平台配置。

点击档案入口后，一秒连接动画与目标阅读资源预取同时开始。构建在各页输出中注入 `archive-prefetch` JSON 清单，包含内容地址样式和 defer 阅读脚本，排除模型 template；当前页已经使用的 URL 不重复预取。发布版直接使用清单，省去准备阶段的目标 HTML 请求。源码预览未构建时仍可从目标 HTML 提取资源；准备失败不影响导航。HTTP(S) 准备和跳转使用目录地址，避免平台再次重定向 index.html；锚点、查询参数与一秒转场保留，file:// 继续使用 index.html。

## 动画与布局

八页公共模型调度设为 60 FPS，天王星保留原调度；静止、离屏和后台继续休眠。实际帧率受设备性能与屏幕刷新率限制。金星初始球体和光晕适配容器短边的约 68%，窗口变化保留方向与相对缩放。

## 验证入口

`npm run check` 检查精确路径（含 srcset）、脚本语法、原素材完整性、确定性构建、CSS 重定位、内容哈希、调度与迟到纹理清理。

`npm run check:browser -- loading performance model-runtime` 覆盖隐藏模型无请求、脚本失败与超时、迟到入口、选中目标保留、按需月球和木星贴图、巡视器深链接、同页 JPG 复用、WebP 预览/原图弹窗、跨档案缓存复用、动画中预取、离线模型、金星尺寸和模型调度。`npm run check:all` 还覆盖原文、全站交互、轨道、音乐和旧缓存升级。

浏览器与本机限速测量只用于回归和比较，不代表中国大陆运营商的实际网络速度。
