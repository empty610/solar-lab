# 第二阶段：模型加载与动画调度

日期：2026-10-19。延续原生 HTML/CSS/JavaScript 架构。

## 这次解决的问题

水星、金星、火星、木星、土星、海王星、木卫二在暂停或减少动态效果时，仍持续重绘三维场景。水星、木星、土星、海王星、木卫二离开视口后还在申请动画回调。冥王星已经避免静止重绘，但仍不断申请空回调。

现在这些页面使用 `shared/model-runtime.js`：

- 自转、自动环绕、镜头过渡和拖动惯性尚未结束时继续绘制；静止后停止申请动画帧。
- 拖动、缩放、照明、复位、天体切换、轨道时间变化和尺寸变化会唤醒画面。
- 模型离开视口、标签页进入后台或触发 pagehide 时取消调度。恢复时重新计时，不把离开期间的时间一次性补算。pageshow 支持浏览器返回后的恢复。
- 响应式布局变化后，核对迟到的可见性通知是否仍对应当前几何位置，防止取消最终尺寸下的绘制而留下空白画布。
- 各页面继续管理自己的几何、科学参数、照明、镜头过渡和界面；共享代码只负责帧与贴图的生命周期。

天王星原本已有按需调度和迟到贴图保护，本轮保留其实现，继续使用原有专门回归检查。

## 60 FPS 更新（2026-10-20）

共享模型调度器默认目标为 60 FPS，八个接入模型统一使用该目标，取消金星、火星、土星、海王星和冥王星原来的 30–40 FPS 限制。调度器允许 1 毫秒的时间戳误差，并独立保留帧间隔余量，避免 60 Hz 回调因舍入或轻微抖动而隔帧绘制；科学动画仍只累计实际经过的时间。

天王星、轨道演示和其他交互继续由 requestAnimationFrame 或浏览器 CSS 动画驱动，没有额外的低帧率限制。静止、离屏、后台暂停及减少动态效果设置继续生效。60 FPS 是活动动画的目标，实际帧率仍取决于设备性能和显示刷新率。

模型单元检查覆盖 60 Hz 时间戳舍入与抖动，以及 30、120、144 Hz 回调下的调度频率和时间累计。

2026-10-21 的图片、按目标加载、脚本超时与内容地址缓存见 [加载性能说明](loading-performance.md)。下方历史测量保留各阶段完成时的范围。

## 贴图与失败状态

### 2026-10-21：按可见区域加载依赖

九页三维脚本改放在 `template[data-model-target]` 中，保留普通 src 引用。构建仍验证这些依赖并为应用脚本生成内容版本；原生 template 阻止浏览器提前下载。`shared/model-loader.js` 在对应区域可见、标签页在前台时并行预取该视图的本地依赖，再按依赖顺序执行。科学资料、轨道演示与公共界面脚本继续独立初始化，DOMContentLoaded 不再等待三维素材包。

同页脚本请求复用 Promise，重复进入不会重复加载。模型依赖失败会显示原图文回退并停止后续依赖，公共阅读与弹窗仍可使用；下载期间选中的观察目标会在初始化完成后恢复。保持 file:// 本地脚本加载方式和各页 CSP，不引入内联脚本执行或远端 CDN。

火星原 7.27 MB 卫星包拆为一个 189 字节的边界描述和两份独立近景数据。系统全景先用等效球体定位微小卫星，选择近景时才加载该颗卫星的原 NASA 网格、UV 和贴图；原数据的固定哈希检查与迟到加载失败检查保护其内容和生命周期。参见 `mars/assets/moons/SOURCES.md`。金星的初始观察距离按容器宽高与完整光晕半径适配，目标占容器较短轴的 68%，窗口变化保留观察方向及相对缩放。

`npm run check:browser -- loading` 覆盖九页隐藏区域不下载、显示后只加载一次、独立阅读、依赖错误回退、下载中切换目标、卫星近景请求和失败后的迟到数据，以及总览预览图体积和金星桌面/手机适配。

共享贴图管理器在一个模型实例内按地址与翻转方向复用加载 Promise，保留 sRGB、各页原有 flipY 和最多 4 倍各向异性设置。不同页面和不同翻转方向不会错误共享可变的 Texture。大体积 data URL 直接作为 Map 键，不再为缓存键复制、序列化整段数据。

加载超过 30 秒或解码出错会进入原有图文回退。失败后停止动画、清理已创建的贴图、几何、材质、阴影和渲染器资源；尚未完成的 Promise 会结束，之后到达的贴图直接释放，不再更新材质、进度文字或“就绪”状态。不能中止的底层图片解码可能仍会完成，此处保证其结果不被继续使用。

土星与海王星还会取消尚未执行的天体切换定时器，防止回退后继续切换三维界面。模型失败不影响正文、图片和独立轨道演示。现有水星重试按钮继续通过刷新重建模型；本轮没有增加后台自动重试。

## 镜头与代码维护

水星、火星、木星、土星、海王星、木卫二的窗口适配改为调整观察距离，保留用户观察方向和相对于适配距离的缩放。过渡中的镜头调整目标距离；显式复位按钮仍回到默认视角。冥王星沿用原有方向保持逻辑，并清除复位前残留的拖动惯性。

火星镜头过渡改用动画步长累计时间，后台停留不再导致返回时直接跳到过渡终点；减少动态效果时也不会在过渡结束后重新开启自动环绕。

金星三维脚本从 index.html 拆至 `venus/model.js`，与其余模型脚本一样独立检查语法、生成构建版本。正文、布局、模型素材、第三方库版本和各页视觉设计保持原样。

## 保留的边界

本轮没有迁移框架，也没有改动模型几何数据、内嵌贴图格式、材质外观或加入新 CSS 动画。共享加载器主要修复失败和资源归属；现有各页本来就只加载一份主要贴图，不能据此宣称下载次数或首屏用时明显下降。

大体积内嵌数据仍需下载与解析。若之后继续优化首次进入模型的等待，适合另行评估外置可缓存纹理、压缩素材与延迟初始化，需分别核对画质、离线打开和旧入口兼容。该项不影响当前的按需绘制与失败保护。
