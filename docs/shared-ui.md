# 第三阶段：共享界面与 CSS 动画

日期：2026-10-19。延续原生静态多页结构。

2026-10-21 补充：`SolarUI.activity(elements, onChange)` 以一组关联图表的实际可见性、标签页前后台和 pagehide/pageshow 通知共享时钟是否应调度；用户的播放选择由页面保留。状态变化时才通知，不另建动画循环。用途与测量见 [加载性能说明](loading-performance.md)。

## 这次整理了什么

| 范围 | 原有维护问题 | 当前实现 |
| --- | --- | --- |
| Terminal、火星的标签页 | 两份相近状态机，把 300ms 延时写在 JS 中，与 CSS 动画时长分别维护 | 共用 `SolarUI.tabs`，根据实际 CSS 动画完成切换 |
| Terminal 选中天体的肖像 | 在 JS 内定义关键帧、时长并取消动画 | `selection-arrive` CSS 动画，切换时取消旧动作 |
| 九个档案的影像弹窗 | 关闭、背景点击、滚动锁与返回焦点分散实现，部分页面没有完整恢复 | 共用 `SolarUI.dialog`，各页继续填充自己的正文、图片与来源 |
| 金星、火星的主样式 | 主 HTML 中分别混有约 1400、1700 行样式 | 原样移至各自的 `style.css`，由现有构建生成内容版本 |
| 公共过渡的图层提示 | 跳转遮罩隐藏时仍保留 `will-change` | 只在遮罩挂载期间设置提示 |

没有统一各行星的版式、配色或内容数据格式。主天体正文仍维护在 HTML，科学计算、轨道与三维动画仍由原来的页面模块负责。

## 共享文件的职责

- `shared/ui.js`：标签页状态、有限动画的结束与取消、原生 dialog 的开关、焦点和滚动锁。
- `shared/motion.css`：标签页淡出/进入、肖像选中、弹窗与背景遮罩的有限 CSS 动画。
- `shared/interface.js`：原有返回入口、图片说明准备和跨页连接过渡。
- `shared/interface.css`：原有跨页连接外观与公共影像阅读布局。
- `shared/model-runtime.js`：第二阶段的模型调度与贴图生命周期，本轮未改。

`ui.js` 必须先于调用它的页面脚本加载。其余页面沿用 defer 顺序；金星仍有底部内联页面脚本，所以公共 UI 使用普通经典脚本先行加载。没有引入 ES Modules 或额外运行依赖，保留直接打开本地 HTML 的方式。

## 标签页与动画收尾

`SolarUI.tabs({buttons, panels, onSelect, onShown})` 负责 roving tabindex、方向键/Home/End、aria-selected 和 panel.hidden。`select(id, {animate, focus, shown})` 可以供页面内部导航使用。

页面在 onSelect 更新标题、选择状态或持久化偏好，在 onShown 调整新面板内的布局、唤醒模型或把焦点交给目标内容。火星的巡视器定位改为等待面板实际显示，不再另等 340ms 猜测切换何时完成。

淡出期间，旧面板设为 inert，避免键盘进入即将隐藏的控件。连续点击会取消旧动作，最终只提交最后一次选择；反向点击当前可见面板可以立即恢复。进入系统的“减少动态效果”、切到后台或 pagehide 时，有限动效会完成状态提交并清除临时类与 inert，不留下半切换状态。

动画时长在 CSS 中维护：标签页默认退出 300ms、进入 360ms，肖像选中 320ms。JS 只读取新增有限动画的 finished Promise；没有可用动画时立即提交。不会等待子元素里的轨道、加载指示等无限动画，也不会等待原先已在运行的无关入场动画。

肖像原有的 500ms 首次入场也移到共享 CSS，并通过同一生命周期收尾；不再由旧 img 规则覆盖选中动画。弹窗静止状态显式不运行动画，避免移除临时类后重新触发旧地图入场规则。

## 原生影像弹窗

通过 `const viewer = SolarUI.dialog(element)` 获取同一实例：

```js
// 页面先填充图片、正文和来源，再打开。
viewer.open(trigger);
viewer.close();
// 从地图点击位置直接跳转到对应介绍时，立即关闭。
viewer.close({ animate: false });
```

原生 dialog 继续负责模态语义与焦点约束。关闭按钮、Escape 和真正的背景点击使用同一退出路径，默认退出动画为 180ms；减少动态效果时立即关闭。按下位置在影像内、抬起位置在背景上的拖动不会误关弹窗，点击弹窗本身的留白也不会关闭。

自动化检查应等待 dialog 关闭或 close 事件，再操作背景内容；原有全站地图检查也按这一约定更新。

打开时记录原始触发元素，关闭后用 preventScroll 恢复焦点；相册翻页不覆盖原始触发元素。再次打开会重置弹窗及其说明列的纵向滚动位置。木卫二翻页也重置说明列，避免上一张的阅读位置沿用到下一张。

页面滚动锁由打开的弹窗集合管理：打开第一层时保存 html/body 原有 overflow 值及 important 优先级，最后一层关闭后精确恢复。关闭内层弹窗不会提前解锁页面；关闭动画中重开会取消旧关闭动作，旧异步结果不能再关闭新打开的内容。动态火星地图也使用同一控制器。

每页自己的图片列表、加载/失败提示、上一张/下一张、说明排版和来源链接仍在各页脚本中维护。公共层不复制或重写这些内容。

## 保留的业务时间

没有把轨道、公转、自转和模型镜头改为 CSS 动画。跨页连接仍保留用户原有的一秒交接，音乐偏好、两秒闲置隐藏、提示停留时间、贴图超时也继续按各自用途计时。这里移除的是界面动画与 JS 定时器之间的重复时长维护。

具体收敛范围是公共标签切换、肖像和弹窗，以及巡视器定位对显示完成的等待。模型内部的观察对象切换时序继续在各自的模型模块维护。
