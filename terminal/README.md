# 太阳系总览 · Terminal

这一目录包含总览的全部 HTML、CSS、JavaScript 和八张天体缩略图。星图和天体目录在标签内切换，使用 Mars 页面相同的淡出、淡入过渡；星图文字放在独立图层，并动态避开天体与其他标签。

| 文件             | 用途                                    |
| ---------------- | --------------------------------------- |
| `index.html`     | 页面入口与静态文字                      |
| `app.js`         | 标签切换、选中状态与档案链接            |
| `motion.js`      | 运转、速度、暂停和重置                  |
| `labels.js`      | 标签图层与动态避让                      |
| `style.css`      | 基础样式                                |
| `refinement.css` | 布局与切换动画                          |
| `motion.css`     | 运转控制、独立标签层                    |
| `assets/`        | NASA / JPL 贴图和模型渲染的缩略图与图标 |

单独提交总览变更：在仓库根目录运行 `git add terminal`，然后提交和推送。部署时仍需发布整个仓库，各档案链接使用 `../mercury/index.html` 等相对路径。

缩略图来源与解释沿用对应档案的来源说明；金星采用雷达表面可视化，海王星使用增强色。星图的大小、距离、位置与展示速度为导航示意。
